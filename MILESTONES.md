# NovaIDE Ten-Milestone Roadmap

- **M1 — Foundation:** secure workspace, lazy file explorer, tabs, editor core, themes, autosave and session restore. Completed.
- **M2 — Professional Editor:** highlighting, search/replace, minimap, symbols, folding, bracket matching, multi-occurrence editing and performance mode. Completed.
- **M3 — Project Workspace:** ZIP import/export, smart project detection, workspace hub, global search, templates and resource previews. Completed.
- **M4 — Git + GitHub:** secure connect, clone/pull, commit/push, branches, diffs, merge assistance, Actions and artifacts. Completed.
- **M5 — Android Suite:** Gradle/module inspection, manifest tools, resources, build helpers, APK and log analysis. Completed.
- **M6 — AI and Local Intelligence:** unified encrypted credentials, multi-provider AI, safe patches, autocomplete, snippets, lint, fixes and static analysis. Completed.
- **M7 — Debug and Analysis:** crash/ANR tracing, duplicate/dead-code checks, dependency mapping, security/performance reports and health scoring. Completed.
- **M8 — Plugins and Productivity:** declarative permission-sandboxed extensions, command palette, safe Nova Console, tasks and workflows. Completed.
- **M9 — Web Preview Runtime:** secure static WebView runtime, split preview, live reload, console, viewport modes and SPA fallback. Completed.
- **M10 — Universal Runtime and Final Release:** framework detection, generated-output discovery, Markdown/Mermaid, PWA/WASM support, user-approved Termux execution, loopback server preview, final QA and release hardening. Completed.
